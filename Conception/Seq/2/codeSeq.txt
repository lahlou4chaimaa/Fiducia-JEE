@startuml
skinparam style strictuml
skinparam sequenceMessageAlign center

actor "Candidat" as User
participant "Frontend (React)" as UI
participant "Backend (Spring API)" as API
participant "Database (MongoDB)" as DB
actor "Directeur" as Dir
actor "Administration" as Admin

== Soumission du Dossier (Etape 1) ==

User -> UI: Remplit formulaire (Sujet, Directeur, Pièces PDF)
UI -> API: POST /api/inscriptions (JSON + Files)
activate API
API -> API: Vérifier format documents (PDF/JPG)
API -> DB: Enregistrer Dossier (Statut: ATTENTE_AVIS_DIR)
API -> API: genererNotification(Directeur)
API --> UI: Succès (Dossier Soumis)
deactivate API
UI --> User: Affiche "En attente d'avis directeur"

== Avis du Directeur (Etape 2) ==

Dir -> UI: Consulte dossier candidat
UI -> API: GET /api/dossiers/pendants
API -> DB: Rechercher dossiers
DB --> API: Liste dossiers
API --> UI: Affiche dossiers
Dir -> UI: Donne avis favorable & signe
UI -> API: PATCH /api/dossiers/{id}/avis (FAVORABLE)
activate API
API -> DB: Update Statut: ATTENTE_VALIDATION_ADMIN
API -> API: genererNotification(Administration)
API --> UI: Avis enregistré
deactivate API

== Validation Administrative (Etape 3) ==

Admin -> UI: Vérifie conformité et prérequis
Admin -> UI: Valide administrativement
UI -> API: PATCH /api/dossiers/{id}/valider
activate API
API -> DB: Update Statut: VALIDE
API -> DB: Update User Role: CANDIDAT -> DOCTORANT
API --> UI: Inscription Finalisée
deactivate API

UI --> User: Notification: "Inscription Validée" (Dashboard mis à jour)

@enduml
